# Superpowers Planning Artifacts

This directory contains planning and design documents generated during AI-assisted development sessions using the Claude Code "superpowers" plugin.

- **`specs/`** -- Design specifications created before implementation, capturing requirements and architectural decisions.
- **`plans/`** -- Step-by-step implementation plans broken into phases.

These are historical reference documents. The source of truth is always the code itself. They are kept because they capture design rationale, trade-off analysis, and context that may not be obvious from the code alone.
